## 第二批 A：R3-05 阅读交互

进入条件：R3-03/04 的渲染与位置/设置契约已交接；相关软件阻塞已解决。

产出文件：`docs/plans/r3-05-delivery.md`，必要的现有 REQ/测试更新。

必须完成的可复核场景：

1. 记录 Reader 可见高度、overlap、每次实际位移；5 连翻、首尾钳制、10 次连续操作不越界。
2. 菜单展开/收起及旋转后重算可见高度，TOC 点击后的目标位置符合现有 AC；文档尾部按已有钳制规则评估。
3. 链接、代码复制、表格横滑、长代码横滑、长按和中心菜单使用真实触摸事件，确认不误翻页。
4. 宽表最末列和不换行代码的行尾实际可达；切换阅读模式保持上下文。
5. E-Ink 模式的 smooth scroll、overscroll、ripple、crossfade、无限加载动画等按 REQ 逐项记录；普通模式不回归。

停止条件：页面交互证据闭环；残影/硬件刷新留 R3-09。本任务不实现排版分页引擎、自定义点击区编辑器或新增动画。

## 第二批 B：R3-06 相对资源与外部应用边界

进入条件：R3-03 已交接。R3-05 与本任务共享 ReaderScreen，默认串行实施，避免冲突。

产出文件：`docs/plans/r3-06-delivery.md`，资源样本清单与对应设备结果。

必须完成的可复核场景：

1. 从真实页面点击库内相对链接，覆盖中文、空格、`./`、树内 `../`、跨文档片段、同名标题及不存在的 anchor；核对目标与 TOC 一致。
2. 越出授权树、未知 scheme、目标缺失均给出明确状态，保留当前阅读上下文。
3. https 外链验证实际 ACTION_VIEW 交接；无处理程序验证提示与文档不变，不只测字符串分类。
4. 本地图片使用真实 provider 读取、采样、绘制；切文档、旋转、销毁后无错图或已回收 bitmap 使用。测试超大尺寸图片并记录峰值内存及采样结果。
5. 远程图片仅占位，不调用网络加载路径；记录 manifest/加载器证据。

停止条件：本地资源和系统交互边界验证完成；不添加网络图片、跨库授权或内置浏览器。

## 第三批：R3-07 大文档与检索

进入条件：R3-03/05 已交接。遇到性能问题先定位瓶颈，不直接替换渲染框架。

产出文件：`docs/plans/r3-07-delivery.md`、对应 `docs/performance/` 实测报告。

必须完成的可复核场景：

- 100KB/1MB/5MB/10MB 多小块、巨大段落/代码块经生产读取→解析→页面显示；分别记录读取、解析、首屏可读、峰值内存，不能把 settled PSS 当峰值。
- 加载取消、快速切换文档和后台恢复验证资源释放与迟到结果隔离；耗时判据沿用 REQ，不自行放宽。

停止条件：形成可复测基线与通过/失败矩阵；失败项记录为具体验收缺陷，不开展全库 FTS 或 M2 性能重构。
