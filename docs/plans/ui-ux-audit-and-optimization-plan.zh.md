## 1. 概述与执行摘要

Leaflet 是一款本地优先、目录优先的 Android 平台 Markdown 与 TXT 阅读器，并将墨水屏（E-Ink）设备作为一等公民（First-Class Target）进行深度设计与适配。其底层工程架构与可靠性非常扎实：零内存颠簸的解析管道、支持随时取消的 SAF 目录扫描器、确定性的状态机，以及绝对的数据安全保障（原始文件严格只读，原文字节分毫不动）。

然而，在真机模拟器与源码走查体验中，当前 M1 Alpha 候选版本的用户界面（UI）与交互体验（UX）显露出大量功能原型期的粗糙感与可用性缺陷。部分严重问题直接损害了阅读产品的基本品质，包括：

1. **系统状态栏重叠（Insets Clipping）**：系统时钟、电池与状态图标直接压在各界面的大标题上方（调用了 `enableEdgeToEdge()` 但根布局未处理 Insets 边距）。
2. **布局尺寸与滚动截断缺陷**：未设权重的 `LazyColumn` 嵌套在不可滚动的垂直 `Column` 中，导致书架列表膨胀时将最近阅读、设置与关于按钮挤出屏幕并永久不可见。
3. **表格排版严重错位**：Markdown 表格每行独立渲染，单元格未对齐，表头文字无缝挤压（如 `NameTypeNotes`），失去表格可读性。
4. **小尺寸图片异常拉伸变形**：16×16 px 的图标被无条件 `fillMaxWidth()` 拉伸为全宽 320 dp 的巨大马赛克方块。
5. **墨水屏对比度与色彩失真**：搜索高亮依赖高亮黄（`#FFFF00`），在 16 阶灰度墨水屏上泛白至几乎不可见；未覆写的 Material 3 令牌在单色模式下退化为模糊的浅紫色。
6. **阅读器视口抖动与闪屏**：搜索栏、文档标题与底部工具栏均为流式（In-flow）布局子项，展开/收起时导致文本内容强制重新排版，在墨水屏上引发严重的整屏残影与重绘闪烁。
7. **行内链接粗暴剥离**：Markdown 正文中的链接被全部提取为独立的跨行大按钮堆叠在段落末尾，破坏了文本段落的连贯阅读。
8. **国际化混杂与文案硬编码**：`strings.xml` 中英文杂糅，大量用户可见的扫描状态、错误提示、时间戳在 Kotlin 代码中硬编码为中文，缺乏标准的资源管理。

本文档汇总了体验审计中发现的全部问题证据，给出了针对性的 UI/UX 优化设计规范，并规划了结构化的实施路线。

## 2. 设计原则与不可动摇的约束

所有 UI/UX 优化工作必须严格遵循 Leaflet 的核心工程规范与设计约束：

1. **原始文件绝对不可变**：存储上的所有 Markdown/TXT 原文严格只读。UI 优化绝不得引入任何破坏性文件操作或回写逻辑。
2. **墨水屏一等公民原则**：
   - 严禁任何动效、交叉淡入淡出（Crossfade）、滚动过度发光（Overscroll Glow）或平滑滚动动画（Smooth Scroll）。所有跳转与状态切换必须瞬间就位。
   - 极致对比度：纯黑（`#000000`）与纯白（`#FFFFFF`），辅助以离散的灰度层级（`#EEEEEE`、`#777777`）表达结构分界。
   - 最小化屏幕重绘：避免阅读内容流式尺寸变化引起的二次排版，杜绝墨水屏不必要的波形刷新。
   - 静态反馈：加载状态、复制成功、提示信息必须使用静态呈现，禁止帧动画循环或倒计时重组循环。
3. **触控人机工程**：触控屏上所有可点击交互元素的点击热区最小保证 48×48 dp。
4. **离线与纯粹**：严禁远程图片静默加载、远程字体下载、内置 WebView 或第三方统计服务。
5. **阅读位置持久稳定**：任何排版调节、模式切换或横竖屏旋转，用户当前阅读的块位置必须毫秒级精准还原。

## 3. 问题清单全景录（8 大模块 32 项缺陷）

审计团队在全流程走查中收录了 32 项典型问题，分为 3 个严重度等级：
- **P1（高 / 阻断性）**：造成直接视觉损坏、内容无法辨识、内容截断不可达或对比度严重失效。
- **P2（中 / 可用性）**：造成操作流阻滞、视口抖动、操作提示缺失或交互误导。
- **P3（低 / 细节打磨）**：排版微调、间距不均或次要元数据缺失。

## 4. UI/UX 优化架构与设计规范

为彻底解决上述缺陷且绝不破坏既有阅读逻辑，优化工作遵循以下五大架构支柱：

### 4.1 系统边距与全屏脚手架（Scaffolding）
- 弃用裸 `Column` 作为根界面，采用支持 `WindowInsets` 的标准 `Scaffold`，或显式注入 `Modifier.windowInsetsPadding(WindowInsets.safeDrawing)`。
- 确保所有界面顶部避开状态栏避位区，底部避开手势条或实体导航栏。
- 在 `MainActivity` 清单中补充 `ACTION_VIEW` intent-filter，使 Leaflet 正式具备系统级“打开文档”能力。

### 4.2 墨水屏全阶单色色彩系统
- 完备化 `LeafletTheme` 配色表：
  - `primary = Color.Black`, `onPrimary = Color.White`
  - `surface = Color.White`, `onSurface = Color.Black`
  - `surfaceVariant = Color(0xFFF4F4F4)`, `onSurfaceVariant = Color.Black`
  - `outline = Color.Black`, `outlineVariant = Color(0xFFCCCCCC)`
- 彻底重构搜索高亮：
  - 墨水屏模式：非当前匹配项使用纯粹的 `#CCCCCC`（30% 灰阶）或线框勾勒；当前匹配项使用高对比反色纯黑底白字（`#000000` / `#FFFFFF`）。
  - 标准模式：采用高对比度且符合无障碍规范的主题自适应色彩。

### 4.3 统一组件规范与书架列表重构
- 统领各屏幕标题栏：打造轻量级 `LeafletTopBar`，整合标题、返回/抽屉图标及功能操作。
- 废弃 `●` / `○` 文本按钮，统一采用 Material 3 标准分段按钮（SegmentedButton）或细边框选项卡（Outlined Chip）。
- 将书架列表与最近阅读合并至同一个统一的 `LazyColumn` 中：
  - 顶栏与文件夹添加操作
  - 书架分类头与文件夹卡片
  - 最近阅读分类头与阅读卡片
  - 底部设置与关于快速入口
- 在最近阅读卡片上醒目展示已读百分比标签（如 `35%`）。

### 4.4 浮层化阅读器视口（零重排零闪烁）
- 将阅读器操作条（TopBar、BottomBar、SearchBar）统统移入**绝对定位浮层（Overlay）**，悬浮于正文 `LazyColumn` 之上。
- 正文 `LazyColumn` 占满屏幕并在菜单显隐时**保持视口尺寸绝对不变**，彻底终结视口收缩重排导致的墨水屏残影闪烁。
- 首次进入阅读器时提供优雅的三分触控热区静态引导浮层。

### 4.5 排版与 Markdown 内容呈现优化
- **表格布局**：在渲染前遍历所有行计算各列全局最大宽度；采用等宽对齐单元格与精致的 1dp 细线表格边框。
- **图片尺寸自适应**：取消小图的 `fillMaxWidth()` 限制，按自然尺寸居中排版并设定最大视口约束，杜绝小图标放大成马赛克。
- **行内链接集成**：在 `ParagraphEntry` 中利用 Compose 的 `AnnotatedString` 结合下划线直接行内展示链接，废除段落末尾堆叠全宽大按钮的做法。
- **复制反馈自动淡出**：代码块点击复制后，通过协程在 2 秒后自动恢复为“复制代码”。

### 4.6 规范化双语国际化
- 将全应用所有面向用户的文字提取至 `res/values/strings.xml`（纯正英文默认版）。
- 创建 `res/values-zh/strings.xml` 补齐地道、优雅的简体中文翻译。
- 重构 ViewModel 与 Composable，彻底根绝 Kotlin 源码中的中文字符串硬编码。

## 6. 准出条件与验收指标

1. **工程基线全绿**：`./gradlew test lint ktlintCheck` 全部通过无报错。
2. **双变体兼容验证**：`assembleFullDebug` 与 `assembleEinkDebug` 双产物编译通过，无任何 Lint 警告。
3. **零状态栏重叠**：在任何标准屏幕上，标题与交互项不得与系统状态栏、刘海屏或手势条重叠。
4. **零阅读器视口抖动**：在阅读器内唤起菜单或搜索栏，正文 `LazyColumn` 绝对禁止发生几何尺寸变动与正文重排。
5. **核心保障分毫不伤**：SAF 只读保障、阅读进度毫秒级持久恢复与离线隐私保护完全不受任何影响。
