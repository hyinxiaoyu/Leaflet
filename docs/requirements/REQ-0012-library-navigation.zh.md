# REQ-0012 — 资料库导航（面包屑、稳定扫描状态、行触控目标）

[English](REQ-0012-library-navigation.md) | 中文

Status: READY
Priority: P2
Milestone: M1（UI/UX 优化阶段；上级 UX-05，经任务 NB-00–NB-05 交付）

来源：`docs/plans/ui-ux-audit-and-optimization-plan.md` UX-05（ISS-014–ISS-017）；[资料库导航 UX 计划](../plans/library-navigation-ux-plan.md)；对 [REQ-0001](REQ-0001-folder-library.zh.md)（浏览/扫描）与 [REQ-0004](REQ-0004-display-profiles.zh.md)（显示/运动策略）的局部补充。

## 问题

深层目录导航没有提供跳转到祖先目录的方式：向上只能靠 Back 逐层返回，当前位置也只是一段原始相对路径字符串。扫描进度会在文件列表上方插入和移除文本、按钮与间距，因此每次扫描开始、取消或失败时列表都会跳动。文件行高约 28 dp、内边距局促，文件夹与文档仅靠结尾斜杠区分——既难以点中，在灰阶 E-Ink 屏上也含糊不清。

## 用户故事

作为收藏目录嵌套多层的读者，我希望看清自己当前所在位置并能直接跳到任意祖先目录，希望在扫描进行时文件列表保持不动，也希望有待点击的大尺寸、类型清晰的行，从而快速到达想要的文档且不丢失位置。

## 范围

- 为已打开的资料库提供面包屑 (breadcrumbs)：资料库根目录，加上当前相对前缀 (prefix) 的每个路径分段。点击某个祖先目录即打开该精确前缀；当前分段被明确标识且不触发导航。
- 一个保留的扫描状态区域 (status region)，其外部尺寸不随扫描状态变化，同时 Refresh、Cancel、Retry 以及可恢复的失败/取消信息保持可用。
- 文件与文件夹行具备至少 48 dp 的可点击高度，并随换行名称和更大字号增长；具备区分明显的文件夹/文档提示 (cue) 与可读的 MD/TXT 标签。

包含：`LibraryBrowseScreen`、其行渲染、所需的浏览状态与 ViewModel 动作，以及相应的字符串资源与测试。

不包含（保持原样，归属其他工作包）：UX-04 的 `LibraryListScreen`/Recent 重构、UX-01 窗口安全区 (window insets)、UX-02 E-Ink 调色板工作、UX-10 全量字符串提取、逐目录滚动历史、进程死亡后浏览路径恢复、存储/索引迁移，以及 Reader 行为。

## 非目标

- 不做目录历史持久化，也不做进程死亡后浏览路径恢复。
- 不新增扫描、数据库表或索引变更；面包屑不查询 SAF，也不解析 content URI。
- 不引入全局设计系统、图标库依赖、排序模式或资料库级搜索。
- 不新增资料库管理动作，也不改动扫描算法、取消或索引写入语义。

## 用户体验

1. 在 `Docs/Notes/2026` 下，浏览页显示资料库根目录以及 `Docs`、`Notes`、`2026` 三个分段。点击 `Docs` 显示 `Docs` 的直接子项；点击根目录显示根目录条目。从 `Docs/Notes/2026` 按 Back 恰好上移一层；在根目录按 Back 离开该资料库。
2. 导航到不同前缀时，该目录的列表从顶部开始。点击当前分段不改变状态与滚动位置。
3. 长路径保持可达：面包屑是高度受限、可横向滚动的一行；即使视觉标签被缩短，完整名称仍可访问。
4. 扫描开始、取消或失败都不会移动文件列表：状态文本与其唯一动作位于保留区域内。
5. 文件夹行显示文件夹提示；文件行显示文档提示与 MD/TXT 标签。每行至少 48 dp 高，长名称换行，行随之增高而不是裁切控件。
6. 打开文件仍将原始文档 id 交给 Reader。

## 功能需求

- **FR-1 分段：** 生成资料库根目录，以及当前相对前缀每个路径分段对应的一个分段。根目录为空前缀；每个目标 (target) 都是分段边界上的精确路径前缀。字面百分号字符与大小写保持原样；绝不把 content URI 当作路径字符串。
- **FR-2 受校验的祖先选择：** 由一个 ViewModel 动作选择生成的目标。过期 (stale) 的资料库请求、兄弟目标、越出目录树、外部传入的非法前缀，以及当前目标，都被忽略且不改变状态。祖先选择不需要文件内容或 SAF 查询。
- **FR-3 锚定的面包屑：** 将生成的分段渲染为高度受限、可横向滚动的一行。每个非当前分段都是至少 48 dp 的目标，点击即打开其精确前缀；当前分段在视觉与语义上可识别且没有冗余导航动作；标签被缩短时完整名称仍可访问。
- **FR-4 稳定的状态区域：** 由同一个保留区域承载扫描状态文本及其唯一动作（Refresh、Cancel 或 Retry），覆盖所有状态——`IDLE`、`SCANNING`、`CANCELLING`、`SUCCEEDED`、`FAILED`、`CANCELLED`。在固定可用宽度与字号下，其外部尺寸与状态无关；失败/取消原因保持可用，且不能仅靠省略号隐藏（完整文本仍暴露给无障碍服务）。
- **FR-5 行触控目标与类型提示：** 每个文件/文件夹行整行可点击，高度至少 48 dp，并随换行名称或更大字号增长。文件夹行与文档行具备不依赖颜色的区分提示，以及可读的类型标签（MD / Markdown / TXT）。装饰性图标不产生重复播报。
- **FR-6 保持既有契约：** 空目录仍可选择，目录先于文件的排序与不区分大小写的名称顺序不变，切换到不同前缀时该列表从顶部开始，只读 SAF 边界与扫描取消/索引写入语义不受影响，两个发行版本通过既有显示/运动策略共用同一实现。
- **FR-7 字符串：** 新增用户可见标签进入 Android 字符串资源，并具备英文与简体中文对应文本。此处不提取历史字符串（由 UX-10 负责）。

## 验收标准

- **AC-1（计划 AC-N1）祖先目录：** 在三级前缀下，面包屑显示资料库根目录与每个路径分段。点击祖先目录即打开该精确前缀；当前分段没有冗余动作。Back 恰好上移一层，在根目录按一次即退出。
- **AC-2（计划 AC-N2）路径标识：** 根目录为空前缀；按整段路径匹配，因此 `a` 不是 `ab` 的祖先。大小写、空格、中文名称与字面百分号字符保持原样。只接受为当前资料库生成的根/当前/祖先目标；过期、兄弟、越界或无关目标被拒绝且状态不变。
- **AC-3（计划 AC-N3）长路径：** 在窄屏与 200% 系统字号下，当前位置保持可辨且每个祖先目录保持可达，途径是高度受限、可横向滚动、并提供可访问完整标签的行。分段实测至少 48 dp。
- **AC-4（计划 AC-N4）扫描稳定性：** 在宽度、字号、前缀与已索引行均不变时，`IDLE → SCANNING → CANCELLING → CANCELLED`、`SCANNING → SUCCEEDED`、`SCANNING → FAILED → Retry` 这些转换使列表视口的位置与尺寸、以及首个可见项的键/偏移保持不变，允许 1 物理像素的测量取整。Refresh/Cancel/Retry 保持可操作，失败/取消原因保持可用。文档索引变化或设备配置变化单独测试，不属于「仅扫描状态」不变量。
- **AC-5（计划 AC-N5）行可操作性：** 文件夹行与 MD/Markdown/TXT 文件行的实测可点击边界至少 48 dp；在 200% 字号下长英文/中文名称换行，不裁切控件，也不强制固定行高；空目录仍可选择；打开文件仍把同一文档 id 交给 Reader。
- **AC-6（计划 AC-N6）保持既有契约：** 目录先于文件的顺序与不区分大小写的名称顺序不变；独立资料库、只读 SAF 边界、扫描取消，以及失败后保留上一次索引均保持完好。
- **AC-7 门禁：** JVM/lint/ktlint 门禁与 `full`、`eink` 两个 debug 构建通过，且每条新增用户可见字符串都有英文与简体中文资源。

## 边界情况

空前缀（仅根目录）；单分段前缀；十层路径；含空格、中文、大小写混用与字面 `%` 的名称；名称互相延伸的兄弟项（`a` 与 `ab`）；空目录；两个文件夹同名的资料库；在 Back 之后或资料库切换之后才送达的目标；200% 系统字号；横竖屏；已滚动的内容较多的目录；授权被撤销；带长路径或长原因的失败/取消扫描；极长的文件或文件夹名称；以及仅状态更新时不得重新测量的超长列表。

## E-Ink 考虑

不引入动画、交叉淡入或平滑滚动。面包屑与状态区域均为静态文本与静态目标；当前分段以字重与可访问状态区分，而非仅靠颜色。ripple 与运动遵循既有 DisplayProfile/MotionPolicy。两种运行模式都需覆盖；真实 E-Ink 的残影/刷新行为仍属硬件检查。

## 标准 Android 考虑

Standard 模式使用同一屏幕与同一浏览状态；ripple 与滚动遵循 DisplayProfile。面包屑的横向滚动不参与 Reader 翻页手势，也不新增权限或 intent。TalkBack 阅读顺序仍属设备检查。

## 性能考虑

分段生成与目标校验是纯函数，复杂度与路径深度线性相关。面包屑每次重组都不做 SAF 或索引查询；在固定宽度与字号下，仅状态更新不得重新测量文件列表。此处不声明任何实测阈值；保留区域按受支持的状态/动作布局定尺寸，而不是猜测一个通用高度。

## 存储/数据影响

无。不改 schema、DAO、迁移或 DataStore；浏览前缀保持在内存中的 ViewModel 状态里，本功能不读取、不复制、不写入任何原始文件。

## 测试计划

- JVM：纯分段/目标映射与校验——根目录、三级与十级路径；中文、带空格、大小写混用与字面 `%` 名称；`a` 与 `ab`；非法、过期、兄弟、越界与当前目标——以及在假 `LibraryListSource` 之上的 ViewModel 转换，包括对被拒绝请求的状态不变断言，以及切换资料库后从新根目录开始的断言。既有 `BrowseLevelTest` 与 `LibraryRemovalTest` 保持绿色。
- 基于真实 `LibraryBrowseScreen` 的插桩页面测试（使用假源与可控进度）：点击祖先与根目录、当前分段的空操作、分段与行的可点击边界至少 48 dp、每种扫描状态转换下实测列表边界与首个可见项的键/偏移、长错误/路径、空目录、已滚动的内容较多的目录，以及 200% 字号下的长名称；两种运行显示模式都覆盖。
- 真实 E-Ink 残影/刷新与 TalkBack 检查单独记录，在没有硬件时为 NOT_RUN；软件验收不构成发布声明。

## 实现状态（2026-10-01）

NB-01–NB-05 已实现并通过软件验证；设备、E-Ink 与 TalkBack 检查仍为 NOT_RUN。见[资料库导航体验交付](../plans/library-navigation-ux-delivery.zh.md)。

- **FR-1/FR-2（AC-1/AC-2）：** `Breadcrumbs.kt` 生成资料库根目录以及每个路径边界对应的一项，并按整段路径校验目标。点击以 `AncestorRequest` 携带渲染时的资料库与前缀，`LibraryViewModel.openAncestor` 要求两者仍是当前值，因此过期、兄弟、越界、外部传入或来自其他资料库的目标都会被忽略且不改变状态，当前目录则为空操作（NAV-ACC-01）。回归：`BreadcrumbTest`（8 个 JVM 方法）、`LibraryAncestorNavigationTest`（11 个 JVM 方法）。
- **FR-3/FR-5（AC-1/AC-3/AC-5）：** `LibraryBrowseScreen` 在高度受限、可横向滚动的一行中渲染面包屑——每项至少 48 dp，当前项为粗体、带状态描述且不可点击——并把每个文件/文件夹行渲染为整行宽、至少 48 dp 的目标，带仓库内自绘的文件夹/文档图标、MD/Markdown/TXT 标签与换行名称。浏览列表是受 `weight(1f)` 限制的视口，因此会滚动且 Back 控件始终留在屏幕上。
- **FR-4（AC-4）：** 由同一个保留状态区域承载状态文本（始终两行）与唯一一个动作（Refresh/Cancel/Retry），覆盖每个 `ScanProgressState`；失败与取消仅由 `progress` 承载，因此列表上方不会出现随状态变化的块。`cancelRefresh` 仅在刷新任务活动且状态为 `SCANNING`/`CANCELLING` 时生效，因此延迟到达的 Cancel 不会发布无法终结的 `CANCELLING`（NAV-ACC-02；`LibraryScanCancelTest`，3 个 JVM 方法）。
- **FR-6（AC-6）：** 资料库或前缀变化时，通过提升的 `LazyListState` 把浏览列表重置到顶部，因此已滚动的目录不会把偏移带入下一个目录。
- **FR-7：** 新标签位于 `values/strings.xml`，并在 `values-zh/strings.xml` 中有对应文本。由于 UX-10 尚未交付完整语言对齐，三个默认字符串文件以显式注释抑制了 `MissingTranslation`，该项须随该工作一并移除。
