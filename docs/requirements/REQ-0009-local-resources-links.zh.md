# REQ-0009 — 本地资源与链接

[English](REQ-0009-local-resources-links.md) | 中文

Status: READY
Priority: P0
Milestone: M1

## 问题

AI 资料库是按目录组织的：文档之间用相对链接互引，图片用相对路径存放。用户点击"参见 `../Flink/architecture.md`"或查看相对图片时期望直接可用。若相对链接失效、中文/空格路径打不开、`../` 越界无约束、远程图片静默联网、 content URI 被当文件路径拼接，都会导致阅读中断或安全越界。这是 folder-first 模型的刚性要求。


来源：`docs/archive/init.md` §11–13（Library/扫描模型）、§15（本地相对链接/本地图片相对路径）、§58（offline 默认）；`docs/plans/M0-M1-implementation-plan.md` T10；`docs/research/markdown-renderers.md` §4–5（R5 相对资源桥接）。

## 用户故事

作为按目录管理 AI 资料的读者，我希望点击库内相对文档链接即可跳转、相对图片即可显示，以便资料库的组织关系在阅读器中继续可用。

## 范围

包含：

- 库内相对 Markdown/TXT 链接：`./`、`../`、嵌套目录、含空格/中文路径。
- 目录上跳（`..`）与 fragment（如 `other.md#某个标题`）：fragment 跳到目标文档对应锚点。
- 同文档锚点（如 `#安装步骤`）：滚动到本文对应位置。
- 本地相对图片：相对路径解析、按视口采样解码、解码内存上限、加载可取消与资源释放、缺失/损坏/不支持格式的占位显示。
- 远程图片（`http(s)://`、`//` 等）：不自动联网，显示静态占位。
- 外链（http/https 等外部 scheme）：仅在用户点击时交给外部应用处理。
- 安全规则：基于已授权树（Library root tree URI）和引用文档父目录解析；树内 `..` 允许；越出授权树拒绝；content URI 不当普通文件路径拼接；URI 编码/规范化策略一致；未知 scheme 不执行。

## 非目标

明确不包含：

- 网络图片加载、图片缓存网络栈、内置浏览器。
- 任意跨 Library 访问（链接目标超出本 Library 授权树即拒绝，不跨库解析）。
- PDF/EPUB/音视频等附件内嵌渲染（目标为 MD/TXT 时才跳转；其余见 Edge Cases）。
- 后台预取全库链接有效性、死链全库扫描。
- 图片编辑、保存图片到相册。

## 用户体验

- 可点击的库内文档链接样式可辨；点击后在 Reader 内打开目标文档（当前会话导航），fragment/锚点滚动到对应位置。
- 缺失目标或越权目标：显示明确不可达提示（如"目标不存在或超出资料库范围"），不 crash、不空白卡死。
- 本地图片按文内位置显示；加载中为静态占位，失败为损坏占位（文字说明），不转圈动画（E-Ink 静态优先）。
- 远程图片显示静态占位，注明"远程图片不自动加载"。
- 外链点击弹出外部应用选择或直接交系统处理；无可用外部应用时提示且不 crash。

## 功能需求

- FR-1：解析相对文档链接时以引用文档所在目录为基准，结合 Library 授权树归一化；`./`、`../`、嵌套目录、空格/中文路径均可解析。
- FR-2：规范化后仍位于授权树内的 `..` 上跳允许；越出授权树的结果拒绝并按不可达处理。
- FR-3：content URI 只能经 SAF/DocumentFile 语义访问，禁止字符串拼文件路径；编码（percent-encoding）与规范化（`.`/`..`/多斜杠/尾斜杠）策略全链路一致。
- FR-4：`doc.md#fragment` 跳转目标文档后定位到与 fragment 对应的标题锚点；重复标题的 anchor 冲突解决规则确定且单测锁定（与 REQ-0006 TOC 规则一致）。
- FR-5：同文档 `#fragment` 在本文内滚动定位；无对应锚点时给出明确提示，不跳转到文首假装成功。
- FR-6：本地相对图片经 SAF 打开输入流，按显示视口尺寸采样解码（inSampleSize 或等效），单张解码内存有上限；超限时降采样或占位，禁止 OOM。
- FR-7：图片加载任务可取消（快速滚动/切文档/退出时取消），解码资源及时释放。
- FR-8：缺失/损坏/不支持格式的图片显示占位，不 crash、不阻断正文其余部分渲染。
- FR-9：远程 URL 图片一律不发起网络请求，显示静态占位。
- FR-10：外链点击仅在用户手势下调用系统 intent 交外部应用；未知 scheme 不执行、不 crash。
- FR-11：无可用外部应用处理外链时，给出提示且 Reader 保持当前文档状态。

## 验收标准

- AC-1：给定含空格目录、中文文件名、嵌套 `./` 与 `../` 的 `relative-links.md` 样本，所有树内链接点击后打开正确目标文档（内容一致性断言）。
- AC-2：给定指向授权树外的 `../../escape.md` 链接，点击被拒绝并显示不可达提示，不发生越权读取（单测 + instrumented 双覆盖）。
- AC-3：给定 `other.md#重复标题` 样本，fragment 跳转到与 TOC 规则一致的同一目标（与 REQ-0006 联合断言）。
- AC-4：给定同文档 `#存在锚点` 与 `#不存在锚点`，前者滚动到对应位置，后者提示且位置不变。
- AC-5：给定本地相对图片样本（含大尺寸图），图片可见、内存峰值有界（上限值待 REQ-0011 基线，未验证前只断言不 OOM + 占位/降采样路径被执行）。
- AC-6：给定缺失图片、损坏图片、远程 `https` 图片，分别显示对应占位；无任何网络请求发出（测试侧断言）。
- AC-7：给定 `https://` 外链，点击触发外部 intent（instrumented 用 intent stub 断言）；未知 scheme（如 `foo://`）点击无执行、无 crash。
- AC-8：无可用外部应用时点击外链，提示出现且当前文档内容与位置不变。

## 边界情况

- 链接目标为非 MD/TXT（如 `.pdf`、`.png` 文件直链）：不假装渲染为文档，给出明确不支持提示；图片扩展名走图片路径，其余走不可渲染提示。
- fragment 含 URL 编码（`%E5%AE%89%E8%A3%85`）、大小写、空格/`-` 变体：归一化规则与 TOC 生成规则一致，不一致则记录为实现期冻结项。
- 目标文档被删除/授权丢失：按"文件消失"处理，给出可恢复提示（与 REQ-0001 扫描/授权语义一致）。
- 超大尺寸图片（如数十 MB PNG）：降采样 + 占位，不得 OOM（与 T10 验收一致）。
- 图片与文档同名不同目录、大小写仅异：在大小写敏感/不敏感文件系统下解析结果必须可解释，实现期锁定并记录。

## E-Ink 考量

- 图片加载中/失败占位均为静态（文字 + 简单进度或边框），无旋转 loading、无 shimmer。
- 图片显示为灰度可辨即可，不做彩色增强；抖动/对比处理不引入额外网络或重型 native 依赖。
- 链接点击与图片加载不触发 smooth 滚动或 crossfade。

## Standard Android 考量

- Standard 模式允许图片占位有轻微过渡，但不得掩盖加载失败状态。
- 外链交系统处理的行为与 Standard 分享语义一致；不自建浏览器。

## 性能考量

- 图片按视口采样：只解码显示所需尺寸；列表/长文快速滚动时取消屏幕外图片任务。
- 首次扫描不解析全文（`docs/archive/init.md` §13）：链接有效性不在扫描期全文验证，点击期解析。
- 禁止 O(N²) 的链接归一化；大图内存上限待 REQ-0011 实测，未验证前不编造阈值。

## 存储与数据影响

- 不复制原文、不把图片/文档写入数据库；数据库仅保存索引与阅读状态（`docs/archive/init.md` §12、§58 约束）。
- 图片解码缓存（如有）仅内存或受限临时缓存，不得默认复制全库图片到内部存储；缓存失效随文档关闭。
- 越权拒绝、缺失目标等事件可记轻量日志/状态，不存原文内容。

## 测试计划

- 单测：相对路径归一化（空格/中文/`../`/越界拒绝）；fragment 锚点匹配规则；未知 scheme 拒绝；content URI 非路径拼接（走 DocumentFile/SAF 抽象的单测替身）。
- 样本：`testdata/markdown/relative-links.md`、`relative-images.md`（`docs/archive/init.md` §48）+ 中文路径、嵌套 `../`、重复标题片段、缺失目标的补充样本（T03）。
- instrumented（含真实 SAF provider）：库内跳转、越树拒绝、图片显示与取消、外链 intent stub、无外部应用提示、超大图不 OOM。
- E-Ink 实机：图片、链接点击、缺失目标提示记入 `eink-test-matrix.md`；无设备标 NOT_RUN。

## R3 证据（2026-09-28）

R3-06 验收套件在真实页面上跟踪链接，发现并修复了两个缺陷：DEF-R3-06-01（`runCatching` 吞掉了「没有可处理外部链接的应用」，导致生产中该提示永远不出现）与 DEF-R3-06-02（成功的 `#anchor` 跳转从不滚动，因为待处理跳转的 effect 不会重新运行）。跨文档片段、重复标题、未知锚点、越树拒绝、中文相对路径、远程占位和图片缺失占位现已在页面上覆盖。真实 provider 的图片链路现由 `ReaderImagePipelineTest` 覆盖（实时 provider、解码预算内的采样、像素校验、缺失/撤销授权、取消），中日韩/空格/`../` 路径经真实 `DocumentSourceImpl` + DAO 由 `DocumentSourceImplTest` 覆盖。图片条目在旋转/销毁时的回收与页面级中文链接点击仍未验证。见 [r3-06-delivery.zh.md](../plans/r3-06-delivery.zh.md)。

- 非 MD/TXT 目标提示文案：T10 已冻结（media notice，不渲染）。
- 跨 Library 链接：默认拒绝（T10 落地），变更需另立 REQ。
