来源：`docs/archive/init.md` §15（MVP：TOC、点击跳转）、§26；`docs/plans/M0-M1-implementation-plan.md` T06（标题提取）/T08（TOC 层级、重复 anchor、点击跳转）；`docs/research/eink-readers.md` §5（TOC 与渲染块模型同源：Pilcrow `ParseMarkdownHeadingsUseCase` 教训）。

## 问题

AI 生成的长 Markdown 动辄数百标题，没有 TOC 只能靠翻页盲找。TOC 必须与渲染内容同源——若 TOC 解析与渲染各算一套，重复标题、特殊字符标题、frontmatter 干扰下跳转必错位。需要与渲染块模型同源的层级 TOC：重复标题有稳定 anchor，点击即落到对应内容块。

## 用户故事

- 作为长文档读者，我希望打开大纲查看 H1–H6 层级结构，以便快速把握文档骨架。
- 作为研读用户，我希望点击标题后跳到对应正文，以便在章节间快速穿梭。
- 作为阅读含重复标题（如多节“总结”）的用户，我希望每个同名标题都能跳到各自位置，以免被锚点冲突误导。

## 范围

包含：

- TOC 构建：与渲染块模型同源（同一解析产物 `ParsedDocument.blocks` 派生），层级为 H1–H6，保留嵌套缩进；空标题/无标题文档显示占位（“无章节标题”）。
- 重复标题 anchor：同名标题分配稳定唯一 anchor（后缀计数规则实现记录，如 `总结`、`总结-1`、`总结-2`），跳转一一对应。
- 点击跳转：落到对应内容块顶部（考虑 viewport 顶部遮挡偏移），E-Ink 用 instant；跳转后目标块可静态标识（如无动画的短暂底线/加粗指示，实现记录，未验证）。
- 跳转与 REQ-0003 位置管线复用：跳转落定后保存位置；模式切换（CONTINUOUS/PAGE_TURN）不影响 anchor 有效性。
- TXT：无 Markdown 标题则无 TOC（占位），不伪造章节。

## 非目标

明确不包含（计划 §1 不做项适用）：编辑器、AI 总结大纲、PDF/EPUB 目录、双链知识库、插件、全库 FTS、书签/标注系统（跳转指示不是书签）、缩略图页映射、可配置手势、大屏双栏、复杂动画；以及：基于源码行号/offset 的独立 TOC 解析器（必须同源，禁止另算一套）、goto 页码输入框。

## 用户体验

1. 入口：阅读菜单 → “目录”；抽屉/底部表列出层级标题（缩进区分 H1–H6），当前阅读所处章节静态高亮（节流更新，不闪烁）。
2. 点击标题 → 抽屉关闭（或保留，行为实现记录）→ 内容落到对应块；E-Ink 无平滑滚动、无闪烁动画。
3. 重复标题各自成行，点击分别落到不同位置。
4. 无标题文档：显示“本文档无章节标题”占位。
5. 跳转误差：目标块顶部可见（被顶部栏遮挡则留出偏移），判定见 AC。

## 功能需求

- FR-1（同源）：TOC 从同一 `ParsedDocument` 块模型派生，与渲染共用 heading 块序列；禁止用独立正则/二次解析另算一套 TOC。（映射 T08“与渲染块模型同源”）
- FR-2（层级）：保留 H1–H6 六级层级关系供 UI 缩进；跳级标题（如 H1 直跳 H3）按实际层级展示，不重排改写。（映射“TOC 层级”）
- FR-3（重复 anchor）：相同标题文本（归一化规则实现记录：大小写/空白/标点处理）分配唯一 anchor，后缀计数确定且跨解析稳定（同内容同指纹下 anchor 序列一致）；跳转按 anchor → 块索引，不按文本查找。（映射“重复标题 anchor”）
- FR-4（点击跳转）：点击 TOC 项滚动到对应块顶部（扣除顶部栏/Sticky 遮挡的偏移）；E-Ink instant；落定后按 REQ-0003 保存位置。（映射“点击跳转”）
- FR-5（frontmatter 安全）：frontmatter/代码块内的 `#` 不得进入 TOC；异常 frontmatter 不影响 TOC 构建。
- FR-6（TXT）：TXT 无 TOC，占位展示，不生成伪章节。
- FR-7（当前位置映射）：TOC 当前章节指示经渲染位置映射计算（块索引区间），禁止把源码 offset 当屏幕坐标。（映射 T11 同类约束方向）

## 验收标准

- AC-1：给定含 H1–H6（含跳级 H1→H3）样本 → TOC 行数 = heading 块数，层级缩进与级别一致；frontmatter/代码块内 `#` 零进入。
- AC-2：给定含 3 个同名“总结”（分布不同章节）样本 → 3 个 anchor 互异且跨两次解析一致；逐个点击 → 分别落在 3 个不同块顶部（`blockIndex` 各异且与 anchor 映射一致）。
- AC-3：点击任意 TOC 项 → 目标块顶部在视口可见区内（顶部遮挡偏移已扣除，误差 ≤ 4px），E-Ink 无平滑滚动；落定后位置记录 `blockIndex` = 目标块。
- AC-4：无标题 MD 与 TXT → 显示无章节占位，无 crash、无伪造条目。
- AC-5：1000+ 标题文档 → TOC 可打开、可点击跳转，无 ANR（实测记录，未验证阈值）。
- AC-6：无“支持 XXX”空话：行数、anchor 序列、落位块索引均有断言。

## 边界情况

- 空标题（`#` 后无文本）、标题内含行内格式（粗体/代码/链接）：TOC 显示可见文本，anchor 归一化规则覆盖。
- 标题含 emoji/中文/特殊字符：anchor 稳定，不抛异常。
- 文档解析降级（未知语法块）：heading 块不受影响；全篇降级为纯文本时 TOC 为空 + 占位。
- 跳转目标块在尾部 clamp 区：落位遵循 REQ-0005 尾部规则，不越界。

## E-Ink 考量

- 跳转 instant；当前章节高亮为静态（节流更新 ≥ 1s），无闪烁/动画指示；抽屉开合无过渡动画。

## Standard Android 考量

- 同一管线；Standard 允许抽屉正常滚动特性，但跳转落位语义一致；无专属 TOC 解析路径。

## 性能考量

- TOC 派生 O(heading 数)；anchor 构建单次线性 pass；1000+ 标题列表复用回收，不一次性 inflate 全行（实现记录）。

## 存储与数据影响

- TOC 不单独持久化，随解析产物派生；如列表加速需缓存标题摘要，由实现决定并记录，不存正文。

## 测试计划

- 单测：同源断言（TOC 序列 ≡ heading 块序列映射）、重复 anchor 稳定性（双跑一致）、归一化矩阵（大小写/空白/标点/emoji/中文）、frontmatter/代码块排除。
- Instrumented：点击跳转落位块索引、尾部 clamp、1000 标题性能走查、无标题/TXT 占位。

## 依赖

- REQ-0002（块模型与标题提取）、REQ-0003（落定保存与 anchor 协同）、REQ-0005（跳转滚动语义与 instant 约束）。
- 被依赖：搜索类 REQ（跨块定位复用映射）。
